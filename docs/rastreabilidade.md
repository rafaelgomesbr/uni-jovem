# Matriz de rastreabilidade

Todo requisito do Uni Jovem, com a fase em que é entregue, o critério de aceite que prova que está pronto e a evidência. Atualizada em 14/11/2026, no fim da F0.

## Como ler

**Estados**, do menos para o mais avançado. Um requisito só sobe de estado com evidência registrada na coluna "Evidência".

| Estado                   | Significa                                                                              |
| ------------------------ | -------------------------------------------------------------------------------------- |
| planejado                | Previsto no plano; nada feito ainda.                                                   |
| implementado             | Código existe, mas sem teste automatizado que prove o critério.                        |
| testado auto             | Teste automatizado cobre o critério e passa no `npm run verificar`.                    |
| testado auto (parcial)   | Parte do critério tem teste automatizado; o que falta está em "Pendências".            |
| validado visual          | Conferido na tela (captura ou revisão registrada), nas larguras e temas pedidos.       |
| validado dispositivo     | Conferido em aparelho real ou simulador, com registro.                                 |
| validado serviço externo | Conferido contra o serviço real (Resend, FCM, APNs, lojas, Cloudflare).                |
| publicado                | Em produção ou nas lojas, com aprovação explícita do dono registrada.                  |
| bloqueado/pendente       | Não pode avançar; o motivo (em geral uma pendência humana PH-nn) está em "Pendências". |

**Dependências** citam outros IDs desta matriz, fases (Fnn) ou pendências humanas (PH-nn, em [`PENDENCIAS-HUMANAS.md`](PENDENCIAS-HUMANAS.md)).

**Resumo em 14/11/2026:** 3 requisitos em "testado auto (parcial)" (PAP-01, SEG-02, OPS-01); todos os demais em "planejado".
